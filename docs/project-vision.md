# PPG Management & Learning Monitoring System

Aplikasi Laravel untuk mengelola pembinaan generus PPG.

Implementasi awal:
PPG Karawang Timur.

Struktur organisasi:

Daerah
└── Desa
    └── Kelompok

Aplikasi mengelola:

- Generus
- Guru
- Orang tua/wali
- Kurikulum
- KBM
- Absensi
- Evaluasi
- Munaqosah
- Rapor
- Pelatihan
- Komunikasi
- Laporan
- Dashboard

Prinsip utama:

Semua data bisnis harus dynamic/database-driven.

Penambahan Desa, Kelompok, Jenjang, Materi,
Guru, Program, Status, Tahun, Semester,
dan konfigurasi lainnya harus dapat dilakukan
melalui aplikasi tanpa mengubah source code.
