# PPG Glossary

DPD = Daerah
PC = Desa
PAC = Kelompok

Generus = Generasi Penerus

KBM = Kegiatan Belajar Mengajar

Dewan Guru = Tenaga Pendidik

Bidang Kurikulum = Bagian yang mengelola program dan monitoring kurikulum pembinaan
